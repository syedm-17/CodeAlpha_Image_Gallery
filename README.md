# CodeAlpha_Image_Gallery
Project Description
This is a hybrid image gallery project built using HTML, CSS, and JavaScript. The gallery showcases a sleek and modern design, featuring a curated collection of car and horse images. The layout is fully responsive, ensuring smooth and consistent viewing experiences across all devices, from desktops to mobile screens.

Interactive hover effects have been applied to enhance user engagement, offering subtle animations and visual transitions as users interact with the gallery items. The combination of clean code structure and elegant styling makes this project both visually appealing and efficient.

Whether you're browsing high-performance cars or graceful horses, this image gallery provides an organized, interactive, and polished interface for viewing images seamlessly.
